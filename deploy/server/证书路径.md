# 全唐诗 tp 证书 — 唯一约定（不再改）

## 用哪一个？

**只用这一处：**

```text
/data/qts/cert/tp.textengine.cn_bundle.crt
/data/qts/cert/tp.textengine.cn.key
```

与 PostgreSQL（`/data/qts/pgdata`）、Meilisearch（`/data/qts/meili`）同属全唐诗数据盘，**与清嘉录目录无关**。

## 不再使用的路径（历史误写，请勿新建）

| 路径 | 说明 |
|------|------|
| `/data/certs/tp.textengine.cn/fullchain.pem` | 曾误写，**作废** |
| `/data/qjl/app/cert/tp.*` | 清嘉录目录，**全唐诗不要用** |

## 若证书已放在错误目录

在服务器上**一次性**挪到正确位置即可：

```bash
sudo mkdir -p /data/qts/cert
# 若曾在 /data/certs/tp.textengine.cn/：
sudo cp /data/certs/tp.textengine.cn/fullchain.pem /data/qts/cert/tp.textengine.cn_bundle.crt 2>/dev/null || true
sudo cp /data/certs/tp.textengine.cn/privkey.pem   /data/qts/cert/tp.textengine.cn.key 2>/dev/null || true
```

文件名必须是 `tp.textengine.cn_bundle.crt` 与 `tp.textengine.cn.key`（与仓库里所有 Nginx 配置一致）。
