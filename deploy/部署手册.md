# 全唐诗检索 — 生产部署手册（tp.textengine.cn）

面向 **零基础**：按顺序复制命令执行即可。  
目标：在腾讯云 **43.142.176.9**（与清嘉录同机）上线 **https://tp.textengine.cn**。

---

## 你将得到什么

- 浏览器打开 `https://tp.textengine.cn` 可检索全唐诗（约 4.1 万条索引）
- 清嘉录 `https://qjl.textengine.cn` **不受影响**
- 数据在数据盘 `/data/qts/`，代码在 `/opt/quatangshi`

---

## 一、准备清单（动手前勾选）

| 项 | 说明 |
|----|------|
| ☐ 域名权限 | 能登录 `textengine.cn` 的 DNS 控制台 |
| ☐ 服务器登录 | 能用 **`ssh ubuntu@43.142.176.9`** 登录（腾讯云 Ubuntu 默认禁用 root 直连，属正常） |
| ☐ 清嘉录已运行 | `https://qjl.textengine.cn` 能打开（说明 80/443 已被清嘉录容器使用） |
| ☐ GitHub 仓库 | 代码在 https://github.com/cobrayao-blip/Suzhou-in-Tang-Poetry- |
| ☐ 约 30–60 分钟 | 首次构建镜像 + 导入索引 |

**密码本**：准备两个小本本，分别记下（不要发给他人）：

1. `POSTGRES_PASSWORD`（PostgreSQL）
2. `MEILI_MASTER_KEY`（Meilisearch，建议 32 位以上随机字母数字）

可用 PowerShell 生成随机串：

```powershell
-join ((48..57 + 65..90 + 97..122) | Get-Random -Count 32 | ForEach-Object {[char]$_})
```

## 二、配置域名 DNS

1. 登录购买 `textengine.cn` 的域名服务商（腾讯云 DNSPod 等）。
2. 添加 **A 记录**：

| 主机记录 | 记录类型 | 记录值 |
|----------|----------|--------|
| `tp` | A | `43.142.176.9` |

3. 保存后等待 **5–30 分钟** 生效（部分地区更久）。

**检查（在你自己电脑上，可选）：**

```powershell
nslookup tp.textengine.cn
```

应看到地址 `43.142.176.9`（未生效时先继续后面步骤，最后再测网站）。

## 三、用 SSH 登录服务器（Windows）

### 3.1 打开终端

- 按 `Win + R`，输入 `powershell`，回车。

### 3.2 登录（用 ubuntu，不要用 root）

```powershell
ssh ubuntu@43.142.176.9
```

- 第一次会问 `Are you sure you want to continue connecting?`，输入 `yes` 回车。
- 按提示输入 **ubuntu 用户密码**（或密钥 passphrase；输入时屏幕不显示字符，属正常）。

登录成功后，提示符类似 **`ubuntu@VM-xxx:~$`**，表示已在服务器上。

> **`ssh root@43.142.176.9` 连不上是正常的**：腾讯云 Ubuntu 镜像默认关闭 root 密码登录，请始终用 **ubuntu**，需要管理员权限时在命令前加 **`sudo`**（见下一节）。  
> 密钥登录示例：`ssh -i C:\path\to\your.pem ubuntu@43.142.176.9`

### 3.3 关于 sudo（必读）

本手册中，凡需要创建 `/data`、`/opt`、安装软件、运行 Docker、改清嘉录配置的命令，均已写上 **`sudo`**。  
执行后若提示输入密码，填 **ubuntu 用户的密码**（不是 root 密码）。

验证 sudo 是否可用：

```bash
sudo whoami
```

应输出 `root`。

（可选）若希望以后不用每次加 `sudo docker`，可执行一次 `sudo usermod -aG docker ubuntu`，然后 **断开 SSH 重新登录**；本手册为省事仍统一写 `sudo docker`。

## 四、服务器：挂载数据盘与目录

以下命令均在 **SSH 里**执行（服务器上），需要权限处已加 `sudo`。

### 4.1 查看磁盘

```bash
lsblk
df -h
```

确认有 **约 60G 的数据盘**（常见设备名 `vdb`，挂载点 `/data`）。  
若尚无 `/data`，需先在腾讯云控制台挂载并格式化（仅新机需要；清嘉录若已用 `/data`，可跳过格式化）。

### 4.2 创建全唐诗目录

```bash
sudo mkdir -p /data/qts/pgdata /data/qts/meili
sudo mkdir -p /opt/quatangshi
sudo chown ubuntu:ubuntu /opt/quatangshi
```

### 4.3 PostgreSQL 数据目录权限

```bash
sudo chown -R 70:70 /data/qts/pgdata
```

（PostgreSQL 官方镜像内用户 UID 为 70。）

## 七、生成索引文件（必做，在构建 Docker 之前）

仓库 **不包含** `index/quatangshi_phase1.jsonl`（太大、可重建），须在服务器生成一次：

```bash
cd /opt/quatangshi
python3 tools/build_phase1_index.py
```

约 1–3 分钟。完成后检查：

```bash
ls -lh index/quatangshi_phase1.jsonl
```

应看到约 **20MB+** 的文件。若没有，不要继续，先排查 `python3` 是否可用：

```bash
python3 --version
```

## 八、配置环境变量

```bash
cd /opt/quatangshi
cp deploy/.env.prod.example deploy/.env.prod
nano deploy/.env.prod
```

在 `nano` 中：

1. 把 `POSTGRES_PASSWORD=change-me-strong` 改成你在「准备清单」里记的密码。  
2. 把 `MEILI_MASTER_KEY=change-me-meili-master-key` 改成另一串随机密钥。  
3. 确认以下行（一般不用改）：

```env
TP_HOST=tp.textengine.cn
CORS_ORIGINS=https://tp.textengine.cn
QTS_HTTP_PORT=18080
PGDATA_HOST_PATH=/data/qts/pgdata
MEILI_DATA_PATH=/data/qts/meili
```

保存退出：`Ctrl+O` 回车，再 `Ctrl+X`。

## 九、构建并启动 Docker

仍在 `/opt/quatangshi`：

```bash
sudo docker compose -f deploy/docker-compose.prod.yml --env-file deploy/.env.prod up -d --build
```

**首次约 10–20 分钟**（下载镜像、编译前端）。

查看是否在运行：

```bash

```

应看到 `postgres`、`meilisearch`、`api`、`web` 为 **running**（或 healthy）。

## 十一、HTTPS 与域名（与清嘉录共用 443）

清嘉录的 Docker **已占用** 服务器 80/443，因此 **不能再单独装一套占用 443 的 Nginx**。  
做法：在 **清嘉录** 的 Nginx 里增加 `tp.textengine.cn`，转发到本机 `18080`。

### 11.1 申请 tp 子域证书（在服务器上）

若已有 **`*.textengine.cn` 通配符证书** 且文件名匹配，可跳过本节，直接把证书放到 `/data/qjl/app/cert/` 并在下节改路径。

使用 certbot（宿主机已安装时）：

```bash
sudo apt-get install -y certbot
sudo certbot certonly --standalone -d tp.textengine.cn \
  --pre-hook "sudo docker stop \$(sudo docker ps -q --filter publish=443) 2>/dev/null || true" \
  --post-hook "cd /data/qjl/app && sudo docker compose -f docker-compose.prod.yml --env-file .env.docker.prod up -d web"
```

> **说明**：standalone 模式需短暂占用 80 端口，会短暂影响清嘉录；请在访问低峰操作。  
> 若你更熟悉腾讯云 DNS 验证，可用 `certbot certonly --manual` 或控制台申请证书后下载到服务器。

将证书放到清嘉录使用的目录（与 `qjl.textengine.cn` 同级），例如：

```bash
sudo mkdir -p /data/qjl/app/cert
sudo cp /etc/letsencrypt/live/tp.textengine.cn/fullchain.pem /data/qjl/app/cert/tp.textengine.cn_bundle.crt
sudo cp /etc/letsencrypt/live/tp.textengine.cn/privkey.pem   /data/qjl/app/cert/tp.textengine.cn.key
sudo chmod 644 /data/qjl/app/cert/tp.textengine.cn_bundle.crt
sudo chmod 600 /data/qjl/app/cert/tp.textengine.cn.key
```

### 11.2 修改清嘉录 Nginx 配置

清嘉录项目路径以你服务器为准，常见为 **`/data/qjl/app`**：

```bash
cd /data/qjl/app
sudo cp deploy/nginx.docker.conf deploy/nginx.docker.conf.bak.$(date +%F)
sudo bash -c 'cat /opt/quatangshi/deploy/qingjialu-nginx-tp.snippet.conf >> /data/qjl/app/deploy/nginx.docker.conf'
```

（也可用 `sudo nano deploy/nginx.docker.conf` 手动把片段粘到文件 **末尾**，不要删掉原有清嘉录配置。）

同时确认清嘉录 `docker-compose.prod.yml` 里 **web** 服务有（没有则加上）：

```yaml
    extra_hosts:
      - "host.docker.internal:host-gateway"
```

### 11.3 重建清嘉录 web 容器使 Nginx 生效

```bash
cd /data/qjl/app
sudo docker compose -f docker-compose.prod.yml --env-file .env.docker.prod up -d --build web
```

确认清嘉录仍正常：

```bash
curl -sI https://qjl.textengine.cn | head -3
```

## 十三、日常更新（从 GitHub 拉取）

服务器上只需仓库里 **生产相关** 的文件（清单见 [`GIT-仓库与生产.md`](./GIT-仓库与生产.md)）。在开发机改完代码并 `git push` 后，SSH 登录服务器执行：

```bash
cd /opt/quatangshi
git pull
python3 tools/build_phase1_index.py
sudo docker compose -f deploy/docker-compose.prod.yml --env-file deploy/.env.prod up -d --build
sudo docker compose -f deploy/docker-compose.prod.yml --env-file deploy/.env.prod --profile bootstrap run --rm bootstrap
```

仅改前端样式、未改 `quantangshi/` 语料时，可省略第二、四行，只执行 `git pull` 与 `up -d --build`。

## 十四、常见问题

### 1. `git clone` 很慢或失败

多试几次，或在本机用浏览器下载 GitHub 的 ZIP 上传到 `/opt/quatangshi` 后解压。

### 2. `docker compose` 提示 command not found

试：

```bash
sudo docker compose version
```

若无输出，安装插件：

```bash
sudo apt-get install -y docker-compose-v2
```

### 2b. `ssh root@...` 提示 Permission denied

请改用 **`ssh ubuntu@43.142.176.9`**，本手册命令已按 ubuntu + `sudo` 编写。

### 3. `build` 时提示找不到 `quatangshi_phase1.jsonl`

先执行第七节 `python3 tools/build_phase1_index.py`，再 `up -d --build`。

### 4. `curl 127.0.0.1:18080` 不通

```bash
sudo docker compose -f deploy/docker-compose.prod.yml --env-file deploy/.env.prod logs --tail=50 api
sudo docker compose -f deploy/docker-compose.prod.yml --env-file deploy/.env.prod logs --tail=50 web
```

常见原因：`.env.prod` 密码未改、构建未完成、内存不足。

### 5. 内网健康但域名打不开

- DNS 是否指向 `43.142.176.9`  
- 清嘉录 Nginx 是否已追加 `tp.textengine.cn` 并重建 **web** 容器  
- 证书文件名是否与 `qingjialu-nginx-tp.snippet.conf` 中一致  

### 6. 内存 4GB 构建失败

可临时加 swap（可选）：

```bash
sudo fallocate -l 2G /swapfile && sudo chmod 600 /swapfile && sudo mkswap /swapfile && sudo swapon /swapfile
```

构建完成后再 `swapoff /swapfile` 亦可保留。

### 7. 清嘉录与全唐诗会互相删数据吗？

不会。PostgreSQL 目录分别为 `/data/qjl/pgdata` 与 `/data/qts/pgdata`，互不影响。
