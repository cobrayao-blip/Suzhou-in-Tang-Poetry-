# 02 — 术语与统计口径

## 2.1 核心术语

| 术语 | 定义 |
|------|------|
| **卷** | 《全唐诗》册次，卷名如 `第一百四十七卷`，对应一个 `text00147.html`。 |
| **篇题块** | HTML 中一个 `p.Bold` 起、至下一篇题或卷末止的结构单元。 |
| **索引条（record）** | Phase 1 中一行记录，默认 **一篇题块一条**。 |
| **诗首（poem head）** | 学界统计单位；一首可独立计数的诗。组诗「十首」= 10 诗首，但可能只有 1 索引条。 |
| **篇内序号** | 篇题中 `卷147_3` 的 `3`，非卷次。 |
| **体裁** | 篇题第一个 `【…】` 内文本；含 `·` 时拆为大类·小类（如乐府）。 |
| **杂录** | 无标准篇题、由解析器按行或片段收录的条目（`parse_note` 标记）。 |

## 2.2 数量口径对照

| 说法 | 约数 | 说明 |
|------|------|------|
| Phase 1 索引条 | **41 375** | 当前 `quatangshi_phase1.*` 行数 |
| 《全唐诗》诗首（通行） | **~48 900** | 清代整理本常见统计 |
| 差额 | ~7 500 | 主要来自「N 首」合条、句编拆条方式不同，非缺卷 |

**禁止**在未说明口径的情况下写「本库共 41375 首诗」。

## 2.3 索引分期简称

| 名称 | 含义 |
|------|------|
| **Phase 1** | 篇题块级索引（已实现） |
| **Phase 2a** | 诗首展开视图（规划） |
| **Phase 2b** | Meilisearch 全文检索、校验、苏州子集 |
| **Phase 2c** | 意象、年表等外源扩展（远期） |

## 2.4 质量标记

| 字段 | 阶段 | 含义 |
|------|------|------|
| `parse_note` | Phase 1 | HTML 解析层异常 |
| `split_note` | Phase 2a | 分首是否经人工确认 |
| `split_confidence` | Phase 2a | 自动分首算法置信度（high/medium/low） |

**原则**：即使 `split_confidence=high`，新建子篇默认 `split_note=needs_review`，直至人工改为 `verified`。

## 2.5 文件角色

| 路径 | 角色 |
|------|------|
| `quantangshi/text*.html` | 权威正文（源真相） |
| `juanmu.xml` | 卷目导航（须与 HTML 卷名一致） |
| `index/quatangshi_phase1.*` | 可由脚本从 HTML 重建的派生数据 |
