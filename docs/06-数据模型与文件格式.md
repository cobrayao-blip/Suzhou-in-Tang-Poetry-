# 06 — 数据模型与文件格式

## 6.1 HTML 正文（`quantangshi/textNNNNN.html`）

### 结构

```html
<h1 class="OneTitle">第…卷</h1>
<p class="Bold">卷{N}_{序}【题名】</p>
<p class="Quotation">作者</p>
<p class="Text">诗句行</p>
<!-- 可选 -->
<p class="PoetryText">联句/句编/格话</p>
```

### 元素语义

| class | 索引用途 |
|-------|----------|
| `OneTitle` | `juan_ming` |
| `Bold` | `pian_ti`（可合并连续 Bold 至 `】` 闭合） |
| `Quotation` | `zuo_zhe`（少数卷篇题在第二 Bold） |
| `Text` | `zheng_wen` 诗句行 |
| `PoetryText` | 无篇题块时的行级收录 |

### 文件名与卷号

- `text00147.html` → 卷号 **147**（用于篇题补全等脚本）。
- 与 `juanmu.xml` 中 `href` 一一对应。

---

## 6.2 卷目（`juanmu.xml`）

### 格式

```xml
<?xml version="1.0" encoding="UTF-8"?>
<juanmu title="全唐诗">
  <item order="1" href="text00001.html">第一卷</item>
  ...
</juanmu>
```

### 约束

- `order`：1..900 连续。
- `href`：须存在对应 HTML 文件。
- 元素文本：与 HTML `<title>` / `<h1>` 卷名一致。

## 6.3 Phase 1 索引

### 存储

- `index/quatangshi_phase1.sqlite` — 表 `poems`
- `index/quatangshi_phase1.jsonl` — 每行一条 JSON

### 字段（当前）

| 字段 | 类型 | 说明 |
|------|------|------|
| `id` | TEXT PK | `{stem}_{序号:04d}` |
| `source_file` | TEXT | 相对路径，如 `quantangshi/text00001.html` |
| `juan_ming` | TEXT | 卷名 |
| `pian_ti` | TEXT | 完整篇题字符串 |
| `zuo_zhe` | TEXT | 作者 |
| `zheng_wen` | TEXT | 正文，`\n` 分行 |
| `ticai_da` | TEXT? | 体裁大类（乐府等） |
| `ticai_xiao` | TEXT? | 体裁小类 / 无大类时的题名 |
| `kuohao_nei` | TEXT? | 第一个【】内全文 |
| `parse_note` | TEXT | 空=正常；否则见术语文档 |

### 索引（SQLite）

- `idx_poems_zuo_zhe`、`idx_poems_juan`、`idx_poems_ticai_da`、`idx_poems_source`

## 6.4 Phase 2a 诗首展开（草案，未实现）

### 表/文件建议名

`index/quatangshi_phase2_heads.jsonl` 或表 `poem_heads`

### 字段草案

| 字段 | 说明 |
|------|------|
| `id` | 如 `text00001_0001_03` |
| `parent_id` | Phase 1 的 `id` |
| `sub_index` | 1..N |
| `sub_total` | N |
| `pian_ti` | 可继承父题 + `·其三` |
| `zuo_zhe` | 继承 |
| `zheng_wen` | 该首诗句 |
| `split_method` | `title_uniform` / `split_plan` / `manual` |
| `split_confidence` | `high` / `medium` / `low` |
| `split_note` | 默认 `needs_review` |

### 分首计划文件（`split_plans`）

```json
{
  "parent_match": "卷1_1【帝京篇十首】",
  "lines_per_poem": [4, 4, 4, 4, 4, 4, 4, 4, 4, 8]
}
```
