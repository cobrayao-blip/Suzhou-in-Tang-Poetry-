# 09 — 工具与运维流程

## 9.1 脚本一览

| 脚本 | 作用 | 是否改语料 | 是否改索引 |
|------|------|------------|------------|
| `corpus_paths.py` | 路径常量 | — | — |
| `build_phase1_index.py` | HTML → Phase 1 | 否 | 是（覆盖） |
| `normalize_juan_titles.py` | 卷名 → 第…卷 | 是 | 否 |
| `normalize_pian_ti_prefix.py` | 卷_N → 卷{N}_ | 是 | 否 |
| `convert_toc_to_juanmu.py` | 旧 toc.ncx → juanmu.xml | 否（迁移） | 否 |
| `validate_corpus.py` | 门禁（规划） | 否 | 否 |
| `build_meilisearch_index.py` | JSONL → Meilisearch | 否 | 是（检索服务） |
| `query_meilisearch.py` | 命令行检索 | 否 | 否 |
| `expand_n_shou_phase2.py` | 诗首展开（规划） | 否 | 是 |

## 9.2 环境

- Python 3.10+ 建议（标准库即可）。
- 项目根执行命令。
- 可选环境变量：
  - `QTS_CORPUS` — 默认 `{ROOT}/quantangshi`
  - `QTS_JUANMU` — 默认 `{ROOT}/juanmu.xml`

## 9.3 标准操作

### 日常：改了几卷 HTML

```bash
python tools/build_phase1_index.py
```

### 从外源拉回一批旧 HTML 后

```bash
python tools/normalize_juan_titles.py
python tools/normalize_pian_ti_prefix.py   # 若篇题出现卷_
python tools/build_phase1_index.py
```

### 更新全文检索（Meilisearch）

```bash
docker compose up -d
pip install -r requirements-search.txt
set MEILI_API_KEY=dev-master-key-change-me
python tools/build_phase1_index.py
python tools/build_meilisearch_index.py
```

详见 [13-Meilisearch检索服务.md](13-Meilisearch检索服务.md)。

### 仅改 juanmu 卷名

```bash
# 须已同步 HTML；或改完后：
python tools/build_phase1_index.py
```

## 9.4 产物说明

| 产物 | 可否删 | 可否手改 |
|------|--------|----------|
| `index/quatangshi_phase1.sqlite` | 可，可重建 | 否 |
| `index/quatangshi_phase1.jsonl` | 可，可重建 | 否 |
| `quantangshi/*.html` | 否 | 是（源） |
| `juanmu.xml` | 否 | 是（与 HTML 同步） |

## 9.6 故障排查

| 现象 | 可能原因 |
|------|----------|
| 索引脚本找不到语料 | `QTS_CORPUS` 或目录名错误 |
| 条数骤降 | HTML 结构改坏、误删 Bold |
| 卷名与卷目不匹配 | 未同步 juanmu |
| Windows 打印路径乱码 | 用脚本输出的相对路径判断即可 |
