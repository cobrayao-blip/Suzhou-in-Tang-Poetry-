# 08 — 语料与版式规范

本文档为 **编辑 `quantangshi/` 与 `juanmu.xml` 的硬性约定**。Agent 规则（`.cursor/rules/quatangshi.mdc`）应与本节保持一致。

## 8.1 卷名

- **格式**：`第` + 中文数词 + `卷`（如 `第十九卷`、`第九百卷`）。
- **禁止**：`卷六百五十八卷`、`卷八百三十`（无「第」或重复「卷」）。
- **同步三处**：
  1. `text*.html` 的 `<title>`
  2. 同文件 `<h1 class="OneTitle">`
  3. `juanmu.xml` 中对应 `<item>…</item>` 文本

## 8.2 篇题（`p.Bold`）

- **格式**：`卷{卷号}_{序号}【题名】`
- **卷号**：与同文件 `textNNNNN` 的 NNNNN 一致（如 `text00147` → `卷147_`）。
- **禁止**：`卷_1【`（缺卷号，已批量修过，勿回退）。
- **篇内序号**：与同卷相邻篇题连续；勿与卷名「第…卷」混淆。
- **多行 Bold**：篇题未闭合 `】` 时，可合并多个 Bold，勿截断。
- **空格**：`【` 前是否空格与同卷既有篇题保持一致。

## 8.3 作者

- 默认紧跟篇题后的 `p.Quotation` 为作者。
- **禁止**将篇题写在 `Quotation` 中（应改为 `Bold`）。
- 作者写在第二个 `Bold` 的卷：保留结构，不擅自删改，可在 `parse_note` 队列处理。

## 8.4 正文

- 诗句用 `p.Text`，一句一行（与现有语料一致）。
- **禁止**用正则批量改正文（标点、异体字易误伤）。
- **禁止**在诗句行末粘连下一首篇题；应拆为独立 `Bold` 篇题块。

## 8.5 特殊卷

| 类型 | 处理 |
|------|------|
| 乐府、歌辞 | 体裁在【】内，常有 `大类·小类` |
| 诗人别集卷（约 121–160） | 篇题已统一为 `卷{N}_` 格式 |
| 句编、联句卷 | 可能大量 `PoetryText`，勿整卷删除 |
| 缺 `】` 篇题 | 体裁可能为空，优先补全括号 |

## 8.6 卷目文件 `juanmu.xml`

- 仅收 **900 卷正文**，不收版权页等占位。
- `href` 必须指向存在的 `text*.html`。
- 不使用外部 NCX/电子书专用命名空间。

## 8.7 修改流程（必守）

1. 只改任务相关卷。
2. 若改卷名 → 同步 `juanmu.xml`。
3. 完成后运行 `python tools/build_phase1_index.py`。
4. 大批量卷名/篇题修正 → 先 `normalize_*` 再重建索引。
