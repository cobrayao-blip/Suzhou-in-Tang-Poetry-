## 3.5 已知遗留问题

1. **`flow0001.css`**：HTML 仍引用，仓库中可能缺失（仅影响浏览器排版，不影响索引）。
2. **组诗未展开**：如《帝京篇十首》仍为 1 条（44 句）；文献分首为 9×4 + 1×8 句。
3. **个别 HTML 结构错误**：需靠 `parse_note` 队列与人工排查。
4. **苏州专题**：无独立索引表，仅能通过正文检索粗筛。
5. **版本管理**：是否使用 Git、是否提交大索引文件 — 见未决问题。

## 3.6 技术栈约束

- **语言**：Python 3，一期仅标准库（sqlite3、json、re、pathlib）。
- **依赖**：Phase 1 仅标准库；检索另需 `requirements-search.txt`（meilisearch 客户端）与 Docker 运行 Meilisearch 服务。
- **运行环境**：本地 Windows 已验证；路径含特殊字符时注意控制台编码（脚本已尽量打印相对路径）。
