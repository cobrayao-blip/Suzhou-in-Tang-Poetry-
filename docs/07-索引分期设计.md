## 7.2 Phase 1 — 篇题块（已实现）

### 目标

从 HTML **忠实抽取**篇题、作者、正文、体裁，服务定位与基础查询。

### 维度

| 维度 | 字段 |
|------|------|
| 定位 | `source_file`, `juan_ming`, `id` |
| 篇目 | `pian_ti`, `kuohao_nei` |
| 作者 | `zuo_zhe` |
| 内容 | `zheng_wen` |
| 体裁 | `ticai_da`, `ticai_xiao` |
| 质量 | `parse_note` |

### 已知偏差

- 一条可含多首（「十首」）。
- 句编卷可能多条对应「一句」。
- 与通行「诗首」不可直接对比。

## 7.3 Phase 2a — 诗首展开

### 目标

在 **不删 P1** 前提下，提供诗首级记录，支撑首数统计、逐首引用。

### 拆分策略（按优先级）

1. **split_plan**：人工/文献给定的句数序列（最高置信，仍 `needs_review`）。
2. **uniform_n**：篇题含「N 首」，总行数 % N == 0，且每首句数 ∈ {2,4,8,12}。
3. **不拆**：记 `shi_shou_declared=N`，`split_note=no_split`。

### 输出

- 子记录 JSONL/SQLite。
- 报告：已拆 / 未拆 / 待复核数量。

### 与 P1 数量关系

```
诗首数 ≈ P1 条数 − 合篇条数 + Σ(每合篇条目的 N−1) ± 句编调整
```

## 7.4 Phase 2b — 检索与专题

### 全文检索（Meilisearch）

- **自建** [Meilisearch](https://www.meilisearch.com/) 服务（见 [13-Meilisearch检索服务.md](13-Meilisearch检索服务.md)）。
- 数据源：`quatangshi_phase1.jsonl` → `build_meilisearch_index.py` 导入索引 `quatangshi`。
- 可搜索：`zheng_wen`、`pian_ti`、`zuo_zhe`、`juan_ming`、体裁字段等；可筛选作者、卷名、`parse_note`。
- 重建：P1 更新后重跑导入脚本（`--recreate` 可选）。

### 苏州子集

- 输入：`tools/lexicon/places_suzhou.txt`（可扩展）。
- 逻辑：标题或正文命中 → 写入 `suzhou_phase1.jsonl`。
- 字段：`match_terms`, `match_scope`。
- **不**从全库删除未命中诗。

### 校验索引（元数据）

- `validate_report.json`：断链、规范违规计数。
